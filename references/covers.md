# 书衣拆分、四封与高清封面

只在用户要求时修改封面编排；普通 MRC 压缩保留原有页面顺序和布局。

当一张扫描图包含封面、前内封、后内封和封底时：

1. 检查扫描图各区边界和书脊，不猜四等分。用裁剪和显示矩阵取出四个面板，尽量共用同一个原扫描 Image XObject，避免存四份全幅图。
2. 四个 PDF 页的页面框与正文一致，不按面板宽度创建窄页。保持长宽比；未覆盖区域填白。
3. 遵守当前用户的对齐要求。历史任务明确要求前内封靠左、右侧白色；后内封靠右、左侧白色。该选择只在同样要求下沿用，不推定所有书都必须如此。
4. 封面、前内封置前，后内封、封底置后；按原书实际结构处理已有封页，避免重复正文或漏页。更新受插页影响的书签、链接和页码映射，原有正文保持。

用户提供独立高清封面时，只替换封面，其余面板继续来自扫描图。直接嵌入原 JPEG 并保留 ICC，不因适配页面而重编码或拉伸；通过显示矩阵等比缩放。若图片比例与正文不同，默认使用留白完整显示；仅在明确要求裁边或铺满时改变策略。

验证四封页面框、对齐和白色填充，检查复用的是同一图像引用，并证明正文页内容/渲染未变。替换的高清 JPEG 可比较嵌入码流与源文件哈希，ICC 也应保留。原 JPEG 哈希一致不代替对最终显示比例、裁剪和方向的目视检查。
