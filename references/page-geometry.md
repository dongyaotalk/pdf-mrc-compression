# 页面尺寸、方向与扫描放置

## 先区分异常

跨册统计 MediaBox、CropBox、旋转、可见内容范围与原生图像像素尺寸。以正常正文的常见纸张尺寸或用户指定的健康前册为参考，不用最大的封面或固定 A4/A5 替全套定尺寸。纸张大小相同不代表字面大小或页边距相同；不要为“统一”而横纵向分别拉伸。

- 封面框比正文大数倍，但像素尺寸相近：优先修正框与显示矩阵。
- 正常横版插页：保留其方向，必要时单独选择横版目标。
- `/Rotate` 与实际像素方向不一致、图像只占一角：先看原生图、相邻页和放置矩阵，再给显式修复计划。不能一律去掉旋转。
- OCR、链接、批注、表单及书签目的地随页面坐标变化；只改 MediaBox 可能裁掉图像或让交互位置错位。

## 等比适配工具

```bash
python scripts/normalize_pages.py source.pdf sized.pdf --plan geometry.json
```

```json
{"size": [420, 590], "pages": [1, 2, 3]}
```

单位为 PDF point（72 point = 1 inch），示例不是默认纸型。省略 `pages` 处理全部页；页码为从 1 开始的物理页。工具将原页面等比缩放并居中补边，保持现有旋转，不解码或重采样原生扫描图；统一五种页面框。正文文字（包括 OCR）保留在原内容流中并随矩阵移动。

支持原点为零、CropBox 等于 MediaBox 的页面；保留显式数值 XYZ 内部跳转、URI、远程链接并移动改变页的链接区域及内部目的地，调整书签位置。非默认 UserUnit、复杂裁切、命名或复杂视图目的地、批注外观和表单不在通用工具的可靠范围内，遇到会停止，需使用能处理对应对象的专门适配器。不能删掉这些内容来绕过限制。

## 显式单扫描方向/放置修复

```json
{
  "size": [420, 590],
  "pages": [28],
  "scan_repairs": [{"page": 28, "rect": [0, 0, 420, 590]}]
}
```

`rect` 是目标页面未旋转的左上角坐标系。只用于已确认“原生扫描方向正确、外层放置错误”的直接单幅扫描页（不从嵌套 Form 提取）：工具复用该图像对象，重新放置到指定矩形并设旋转为零。矩形由检查后给定，可保留真实页边距；保持与原生图的宽高比，避免无意拉伸。存在文字、矢量或复杂结构时拒绝，不会借修复名义删 OCR。

工具只完成计划预检和写入。常规交付要核对页面框、方向、原图码流及代表页显示、OCR/跳转位置；若严格要求视觉不变，几何本身的变化需要明确授权，不能用“像素没重采样”代替说明。用户明确跳过验证时如实记录。
