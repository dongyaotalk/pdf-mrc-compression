# 书签、印刷页码与电子标签

## 三种坐标不要混用

计划中的 `page` 始终是从 1 开始的物理 PDF 页。印刷页码是纸上页码，电子标签是阅读器显示的字符串；例如物理第 4 页可显示印刷/电子页码 773。工具仅在调用 PDF API 时转为从 0 开始。

标签段和书签独立。仅要求改标签时，保留原书签及其手动修改，不顺手重新提取目录；只补书签时不重设标签。不压缩图像、不生成 OCR、不插入额外空白页。

## 书签命名与来源

附属页用“封面”“书名”“版权”“封底”；**“书名”“版权”不加“页”**。若显式重建计划用了旧名“书名页”“版权页”，工具会规范为新名；不改用户原有书签。

- 按实际角色使用“前言”“序”“目录”“总目录”；分部扉页用真实名称，如“魏书扉页”。
- 版权内容只在第一册时，只给第一册设版权书签。位置上的空白不能当作版权页；前三页 ABC 也不代表第三页必为版权。
- 根据印刷目录建立卷、章、篇或人物的层级，并区分目录列出的印刷页码与真实跳转页。保留原书已有书签；合并时先取出现状，再只改授权部分。
- 下册没有印刷目录也可有电子书签，不虚构或插入目录页。
- OCR 可辅助识别少量目录页，结果须与实际标题/页码对应；不默认全书 OCR，也不以 OCR 字体重绘扫描正文。无可用 OCR 时可人工提取显式计划。

## JSON 导航计划

```bash
python scripts/set_navigation.py input.pdf ready.pdf --plan navigation.json
```

```json
{
  "bookmarks": [
    {"level": 1, "title": "封面", "page": 1},
    {"level": 1, "title": "书名", "page": 2},
    {"level": 1, "title": "版权", "page": 3},
    {"level": 1, "title": "卷一", "page": 20},
    {"level": 2, "title": "第一章", "page": 21},
    {"level": 1, "title": "封底", "page": 100}
  ],
  "labels": [
    {"page": 1, "style": "A", "first": 1},
    {"page": 4, "style": "R", "first": 1},
    {"page": 20, "style": "D", "first": 1}
  ]
}
```

示例假设实际有版权且正文起于物理 20；不要照搬页码。`bookmarks` 若提供，表示完整的新书签树（支持页内本地跳转，不表示自动合并原书）；缺省保留。`labels` 若提供，表示完整标签段；缺省保留。空数组显式清除对应结构。`level` 从 1 起，不可跳级；标签段按页递增、首段从物理第 1 页起。`style` 支持 `A/a`、`R/r`、`D` 或空字符串（仅前缀），`first` 默认 1，`prefix` 可选。

常用的**可选排法**：前三页 A、B、C；其余前置内容用大写罗马数字 I 起；正文及后附页用阿拉伯数字，按真实印刷起号与跨册连续编号设置。已编入正文页码的序、分部前言应归数字段；用户选择后，空白尾页和封底可继续数字。前三页后立即正文时不要创建虚假的罗马段：

```json
{"labels": [{"page": 1, "style": "A"}, {"page": 4, "style": "D", "first": 773}]}
```

这不是对所有书的强制格式。核对段首、段尾、分部扉页和最后一页即可避免多数偏一错误；用户要求不校验时直接按确认计划写入，记录未独立核验，不重跑图像检查。
